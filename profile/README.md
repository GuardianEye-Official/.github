## What is Guardian Eye?

Guardian Eye is a local network video recorder for Windows, Linux and macOS. It connects to ONVIF, RTSP/RTSPS and USB cameras, stores recordings on your own disks, and runs video and audio recognition on the recorder itself. No account is required.

The same application can run a small home setup or an installation with more than 100 cameras. Actual capacity depends on the server, network, storage, stream settings and enabled analytics.

## Main capabilities

| Capability | Details |
|------------|---------|
| **Camera support** | ONVIF, RTSP/RTSPS and USB cameras, with network discovery and PTZ controls where the camera supports them |
| **Recording** | One shared capture path per camera, direct archiving of compatible encoded streams, continuous and event-driven recording, pre-record buffer and per-camera schedules |
| **Synchronized player** | Review up to nine cameras at the same wall-clock time, with separate timeline lanes, event filters, marks and a selectable audio source |
| **MCP server** | More than 100 tools let compatible AI assistants work with cameras, events, recordings, PTZ, schedules, zones, storage and diagnostics through scoped access tokens. [Setup guide](https://getguardianeye.com/docs/integrations/mcp) |
| **Home Assistant** | Cameras, sensors, events, snapshots and controls are published over MQTT; the Guardian Eye component adds a dashboard with low-latency WebRTC video. [Setup guide](https://getguardianeye.com/docs/integrations/home-assistant) |
| **Archive recovery** | ONVIF Profile G recovery and FTP/FTPS ingestion for bringing camera-side recordings into the main archive |
| **Local detection** | Motion, objects, licence plates, bird species, sound and camera tampering, with inclusion and exclusion zones |
| **Setup and layout** | A guided setup covers cameras, recording, schedules, zones, storage and notifications; movable camera tiles keep their layout between launches |
| **Notifications** | Desktop, email and Telegram alerts; MQTT events and entities for Home Assistant automations |
| **Hardware acceleration** | NVIDIA CUDA, DirectML, OpenVINO, VAAPI on Linux and Metal on macOS, with software fallback |
| **Languages** | The application and current integration UI are available in 18 languages |
| **Privacy** | Recordings and recognition stay on your computer; the application has no mandatory cloud account or telemetry |
